线上同步设置

      

        
本地数据视为最新。配置线上实例的 URL 与密钥（HMAC 签名），点击「同步到线上」把本地账号、模型配置与客户端参数（UA / 版本号 / 风控头）推送过去。线上实例需配置相同密钥并通过 /api/sync/receive 接收，收到后会自动把客户端参数钉为「已保存」，因此线上无需安装桌面端也能报出与本地一致的真实版本号。

        
        
        
        

          
          
          
          
        

        
密钥基于本机特征自动生成（IP/设备唯一），即使部署到其它电脑也不会重复；可与线上配置相同的自定义密钥。
